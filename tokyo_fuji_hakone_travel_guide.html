先看这页：怎么走最省心

建议按东京 → 河口湖 → 箱根 → 东京机场顺序走，不折返。东京以地铁/JR为主；新宿到河口湖优先坐直达高速巴士；富士山周边第二天建议包车；河口湖到箱根经御殿场转车，行李多可考虑预约出租车/包车。

重要：箱根缆车冬季检修
目前公布的2026年12月7日至24日，大涌谷—早云山段缆车停运；大涌谷—桃源台段另有冬季检修安排。若你们的箱根日落在此期间，不要把空中缆车/大涌谷作为必去项目，按本手册的芦之湖＋箱根神社＋强罗替代路线走，并在出发前再查运营公告。

出行原则

  • 富士山观景安排两天，提升看到晴朗山体的机会。
  • 每天尽量在16:30前完成户外主景点，冬季天黑早。
  • 东京酒店选新宿站南口/西口步行范围，方便去河口湖。
  • 温泉酒店优先订含早晚餐的方案，确认是否含私人风吕。
  • 航班未定前，D7不要安排远距离景点；返程尽量选下午或晚上。

时间为行程建议，不是已购买的车票/预约。日本巴士、列车及设施时刻可能随日期调整。

DAY 01 · 抵达东京

北京 → 东京｜入住新宿

住宿：东京·新宿轻松日
上午 / 中午

北京飞东京

优先选择直飞。落地后按机场指示乘铁路或机场巴士进城。羽田通常更近；成田到新宿预留约1.5–2小时。

抵达后

前往酒店、寄存行李

入住新宿站南口周边。先购买/开通Suica或PASMO交通IC卡；手机可用电子交通卡的旅客可直接添加。

18:00–20:30

新宿夜游

新宿东口、歌舞伎町外圈、思出横丁。第一晚不排预约型景点，吃拉面/烤串后早点休息。

机场进城：羽田可选京急线至品川转JR山手线至新宿，或机场利木津巴士；成田可选Narita Express直达新宿。以航班航站楼和酒店位置决定。

DAY 02 · 东京东部

浅草寺・晴空塔・秋叶原

步行＋地铁传统文化/城市景观
08:30–10:45

浅草寺・雷门・仲见世

从雷门进入仲见世商店街，走到宝藏门和本堂。寺院境内免费；本堂冬季通常约6:30开放。早到人少、拍照舒服。可尝人形烧、仙贝。

11:00–13:00

东京晴空塔

从浅草站乘东武线至东京晴空塔站，或步行跨隅田川约20–25分钟。建议提前预约展望台时段；午餐可在Solamachi商场解决。

14:00–16:30

秋叶原

从押上乘东京Metro半藏门线至锦糸町/住吉再转JR，或按实时导航选择路线。动漫手办、电器、游戏街区自由逛，兴趣一般可缩短。

晚间

回新宿晚餐

建议预留体力，晚餐可选寿喜烧、烧肉或拉面。

浅草→晴空塔导航浅草寺官网晴空塔预约/官网
DAY 03 · 东京西部

明治神宫・原宿・涩谷

JR＋步行购物/城市地标
09:00–10:30

明治神宫

从JR山手线原宿站步行约5–10分钟进入。参道林荫很有氛围，参拜礼仪是先在手水舍净手，再轻声参拜。

10:45–12:30

原宿・竹下通・表参道

竹下通偏年轻潮流和小吃；表参道适合看建筑、精品店和咖啡馆。午餐安排在表参道或原宿。

13:30–15:30

涩谷十字路口・八公像・PARCO

从明治神宫前乘副都心线至涩谷，或步行约20分钟。涩谷PARCO适合动漫、设计和潮流购物。

日落前预约时段

SHIBUYA SKY

建议预约日落前约60–90分钟入场。屋顶露天区域受天气影响，风大/雨雪时可能关闭；按官网当天规则执行。

交通：新宿→原宿：JR山手线约5分钟；原宿/明治神宫前→涩谷：步行或东京Metro副都心线一站。回新宿乘JR山手线约7分钟。
原宿→涩谷SKY导航明治神宫官网SHIBUYA SKY预约
DAY 04 · 东京 → 富士五湖

河口湖・大石公园・温泉

住宿：河口湖·第1晚富士山观景重点
07:30–08:00

从新宿出发

推荐新宿高速巴士总站（Busta Shinjuku）直达河口湖站。车程约1小时45分起，路况拥堵会延长；网上预订指定班次，建议选早班。

10:00–11:00

河口湖站・寄存行李

酒店接驳车需提前问酒店并确认班次；无接驳时打车约10分钟。先寄存行李再开始游览。

11:30–13:00

午餐：ほうとう馎饦面

山梨乡土料理，宽面和蔬菜在味噌汤锅里炖煮，冬天很合适。热门店可能排队，预留时间。

13:30–15:30

大石公园

河口湖北岸经典机位，湖面与富士山同框。晴天时先拍远景，再沿湖散步；云层遮山时可先逛自然生活馆、咖啡馆，晚些再看天气。

15:30以后

入住温泉酒店

建议选富士山景观房并确认“房间朝富士山”，不是仅写“山景”。泡汤前先洗净身体；有纹身者提前确认酒店规定。

首选交通：新宿高速巴士总站 → 河口湖站，约1小时45分，网上票价宣传起价约¥2,000；实际按日期和班次显示为准。大件行李通常可放巴士行李舱，每人件数/尺寸以承运商规定为准。

DAY 05 · 富士山深度游

新仓山・忍野八海・山中湖

住宿：河口湖·第2晚建议包车6–8小时
07:30–09:30

新仓山浅间公园・忠灵塔

导航“Arakurayama Sengen Park / 新倉山浅間公園”。从下吉田站步行约10–15分钟到入口，再爬约400级台阶到展望台。冬季台阶可能结冰，穿防滑鞋；若结冰严重不要勉强登高。

10:15–12:00

忍野八海

八个泉池源自富士山融雪渗透，水色清澈。尊重水池边界，不投喂、不触碰水体；周边有小吃和伴手礼。

12:00–13:00

午餐

可在忍野村吃荞麦面、馎饦面或乡土料理。包车司机休息时段提前沟通。

13:30–15:30

山中湖・长池亲水公园

看湖面、天鹅与富士山。晴天适合拍摄山体倒影；冬季风大，湖边停留注意保暖。日落后迅速降温。

16:00–17:00

回河口湖酒店

若包车时长结束前还有余裕，可在河口湖站附近补给；晚上享用旅馆晚餐或附近餐厅。

为什么推荐包车：这三个点分散，冬季巴士班次和日落时间限制较大。两人包车费用较高，但能显著减少等车和换乘；预订时确认含司机等待时间、儿童座椅（如需要）、高速费/停车费和取消政策。

DAY 06 · 河口湖 → 箱根

御殿场・芦之湖・箱根神社

住宿：箱根·第1晚温泉旅馆
冬季调整：如果此日为12月7–24日，箱根空中缆车部分区间处于检修停运期，不要按常规“箱根空中缆车环线”规划。下面以芦之湖、箱根神社和旅馆为主；出发前确认巴士及游船班次。
08:30–10:00（参考）

河口湖站 → 御殿场站

乘富士急巴士御殿场线，车程约55分钟上下；部分班次需预约。时刻因平日/周末不同，出发前核对具体日期。到御殿场后按酒店位置转出租车或箱根方向巴士。

10:30–12:00

前往箱根住宿区 / 寄存行李

行李较多时建议从御殿场站预约出租车前往仙石原/强罗酒店，节省多段巴士换乘。若预算优先，可用当地巴士，但务必预留候车时间。

12:30–14:00

芦之湖・元箱根港

湖畔散步、看海盗船/观光船。能否看到富士山取决于天气，船班受风浪影响。

14:00–15:30

箱根神社・平和鸟居

湖边鸟居是热门拍照点，排队时间可能较长。请勿越过围栏或在禁止区域拍照；若队伍太长，优先逛神社参道和杉树林。

15:30–16:30

前往旅馆办理入住

入住后泡温泉、享用会席料理。建议预订含晚餐早餐方案，确认晚餐最晚入席时间，避免迟到无法用餐。

建议路线（稳妥版）：河口湖站 → 御殿场站（富士急巴士）→ 出租车/箱根当地巴士 → 元箱根港/箱根神社 → 旅馆。若选强罗的旅馆，景点结束后再乘巴士/出租车上山。

箱根 → 东京机场 → 北京

酒店推荐｜按位置和体验选

以下是候选酒店，不代表已查到房态或价格。预订时重点核对房型、景观、餐食、取消政策和接驳车。

东京首选：Hotel Sunroute Plaza Shinjuku

推荐理由：新宿南口步行约3分钟，靠近Busta新宿，D4坐高速巴士去河口湖非常方便。

建议房型：双人标准房；东京酒店以交通便利、干净舒适为主即可。

地址：2-3-1 Yoyogi, Shibuya-ku, Tokyo

酒店官网地图/路线

河口湖性价比景观：Fuji View Hotel

推荐理由：有富士山方向客房、庭园和室内/露天温泉；酒店有河口湖站接驳车（班次以官网最新信息为准）。

订房要点：明确选“Mt. Fuji view”房型；优先含早餐，想体验怀石料理可订含晚餐方案。

地址：511 Katsuyama, Fujikawaguchiko, Yamanashi

酒店官网接驳/交通说明地图

河口湖升级体验：FUFU Kawaguchiko

推荐理由：高品质森林度假旅馆，所有客房均配露天浴池，适合把富士山住宿作为旅行亮点。

订房要点：预算明显高于普通酒店；查看房间是否有富士山景、晚餐方案和接驳安排。

酒店官网地图

箱根推荐：Hakone Kowakien Ten-yu

推荐理由：每间客房均有露天温泉浴池；从强罗站有免费接驳车，适合最后一晚放松。

订房要点：优先含晚餐和早餐；核对接驳车末班时间、晚餐入席时间。此酒店在小涌谷一带，不在芦之湖边。

交通攻略｜买什么、怎么坐

不建议购买全国JR Pass；本路线以单买城际车票＋东京IC卡为主。是否买箱根周游券，取决于当天实际乘坐的交通工具。

1. 东京市内：Suica / PASMO

地铁、JR、私铁和便利店小额支付都很方便。每人一张实体卡，或在支持的手机钱包中开通交通卡。进出站都刷同一张卡；余额不足在车站充值。

2. 新宿 → 河口湖：优先高速巴士

从新宿高速巴士总站 Busta Shinjuku 4楼上车，直达河口湖站。官方页面显示车程约1小时45分起、班次较多；价格和时刻随日期变动。建议提前在线选座，节假日/周末尤其要提前订。

备选：JR直达特急“富士回游”从新宿到河口湖约1小时53分起，指定席，座位有限；按实际运行日期和班次购票。

高速巴士官方预订富士回游列车时刻/票价

3. 河口湖当地：红线周游巴士 / 包车

红线适合河口湖北岸的大石公园、自然生活馆等景点；站点和班次以官方线路图为准。忍野八海、山中湖与新仓山分散，建议D5包车，或拆成两天并严格对照巴士时刻。

周游巴士线路与时刻河口湖站地图

4. 河口湖 → 御殿场 → 箱根

先坐富士急巴士从河口湖站到御殿场站（约55分钟，具体班次需核对），再转箱根方向巴士/出租车。两人带大行李时，推荐提前预约御殿场至酒店的出租车，减少换乘和搬运行李。切勿把“河口湖—箱根”当成一班直达车。

御殿场线时刻/预订箱根当地交通

5. 箱根周游券：先算再买

Hakone Freepass覆盖指定区域内的登山铁路、登山巴士、缆车、空中缆车和观光船等，但2026年12月存在缆车检修停运。若只住一晚、只坐少量交通，不一定划算；按当天路线核算单程票价后再决定。
